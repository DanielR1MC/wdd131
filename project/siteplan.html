Website Planning Document: FitGuide

Student: Daniel Reyes | Course: WDD 131

1. Site Name

Name: FitGuide (Muscle & Exercise Hub)

Reasoning: The name "FitGuide" is short, memorable, and directly conveys the site's goal: providing an easy-to-use directory for physical exercises categorized by targeted muscle groups.

Optional Domain Availability: fitguide-hub.org

2. Site Purpose

FitGuide provides a structured, accessible educational platform for gym-goers and fitness enthusiasts. It helps users discover exercises categorized by specific muscle groups (chest, back, legs, arms, core), view step-by-step execution instructions, and submit feedback or custom ratings using interactive web features.

3. Scenarios

  • "How do I target my upper chest effectively, and what difficulty level is the incline dumbbell press?"
  • "Where can I submit feedback on a specific exercise or recommend a missing workout routine to the community?"

4. Color Scheme

The color palette is selected to give an energetic, clean, and modern athletic feel:

Primary: Pine Green (#2B5748)
Headers & Footer
Secondary: Olive Green (#9CB080)
Navigation Links
Accent: Yellow (#FFFF00)
Highlights & Accent Text

5. Typography

Primary Font: 'Roboto' (Sans-Serif) - Used for body text, exercise descriptions, and comments due to its clean readability across digital screens.

Secondary Font: 'Montserrat' (Sans-Serif) - Used for headings, category labels, and call-to-action buttons to establish strong visual hierarchy.
